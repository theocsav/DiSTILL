# NOVAE evidence and decision log

This log records reproducible evidence and explicit decisions for the exploratory
NOVAE skin Visium pilot. It is not a confirmatory analysis plan and does not
replace the run report. Pending items remain pending until a separately named,
pre-specified gate is completed.

| Date / gate | Evidence | Decision | Alternatives rejected or deferred | Consequence / next criterion |
|---|---|---|---|---|
| 2026-09 pilot design | NOVAE uses `reference="all"`; prototypes are cohort-derived. | Keep this as exploratory Phase 0/1 evidence. | Do not describe it as held-out or fold-safe classification. | Any confirmatory modeling requires patient-held-out evaluation and a new pre-specified run. |
| 2026-09 scope | NOVAE is being tested as a niche-assignment-stage extension of Myles Tan et al. (arXiv:2509.09923). | Keep the existing Myles downstream methodology as the anchor; keep NOVAE standalone. | Defer DiSTILL integration and downstream feature proliferation. | NOVAE outputs remain niche-assignment QC, not replacement biological endpoints. |
| 2026-09 environment | NOVAE `1.1.1` requires the dedicated Python 3.12 environment; the local checkpoint requested revision `b8c0a5d7612bac6bc719ab57ed3cd16ad814728c`. | Pin the version/revision request and retain checkpoint file hashes in provenance. | A local-directory revision is not treated as independent revision verification; no unpinned compute-node install. | Reproducibility relies on the recorded environment and artifact hashes. |
| 2026-09 graph construction | Visium radius handling required explicit post-construction pruning because NOVAE 1.1.1 did not apply its `radius` argument as intended for `technology="visium"`. | Use the Visium lattice graph and explicitly prune at 100 µm, recording pre/post diagnostics. | Do not substitute a generic radius graph or silently rely on NOVAE's radius parameter. | The completed run later showed 38,107 undirected edges before and after pruning (zero removed), supporting a geometry evidence gate rather than a graph rewrite. |
| 2026-09 job 41152531 | NOVAE emitted zero-filled representations and NA leaves/domains for `neighborhood_valid=False`; the first adapter treated those expected NAs as an error. | Adopt the official invalid-neighborhood NA contract: valid rows must be assigned; invalid rows remain NA. | Do not impute labels, create a literal `"nan"` category, or filter invalid rows silently. | Every resolution audits the shared validity/assignment contract. |
| 2026-09 policy gate | Assignment coverage threshold was declared as 70% overall and for every slide. | Retain the threshold as a fail criterion (`0.70` by default). | Do not use a post hoc threshold or accept an aggregate pass that hides a failing slide. | A future failure requires inspecting coordinates, graph construction, tissue extent, and input QC. |
| 2026-09 job 41197867 | Inference and validation completed, but H5AD serialization failed on list-of-dict radius-pruning provenance. | Serialize provenance in an H5AD-safe form before publishing output. | Do not publish a partially serialized or non-transactional result. | The fix was validated by the subsequent successful job. |
| 2026-09 job 41213616 | Completed in 44 seconds; transactional output published at `h5ad-provenance-fix-20260906_024602/`; 13,372/13,417 rows were assigned and 45 were invalid, with 32 direct isolates. | Preserve this as the declared exploratory run. | Do not rewrite the completed result after seeing QC. | Any rescaling, filtering, or alternate preprocessing must be separately named. |
| 2026-09 calibration review | Adapter graph-edge medians were approximately 78.75 µm, but used the same `spot_diameter_fullres` heuristic being evaluated. Official 10x output semantics identify `pxl_*_in_fullres` as full-resolution centers and `spot_diameter_fullres` as an estimated visualization value; known 55 µm spot diameter / 100 µm center pitch are platform references. | Treat 78.75 µm as provisional broad evidence, not independent microscope calibration. | Defer a correction and do not label the heuristic as validated microscope scale. | A source-geometry audit must precede any calibration sensitivity run. |
| 2026-09 job 42832181 | Read-only H5AD QC completed (`COMPLETED`, `0:0`, 59 seconds) at `h5ad-qc-20260921_064952/`: 13,417 total; 13,372 valid/assigned; 45 invalid; all 0.5/1.0/2.0 domain contracts passed. Cross-tab: nonzero/nonisolated invalid 12, valid 13,372; nonzero/isolated invalid 27, valid 0; zero/nonisolated invalid 1, valid 0; zero/isolated invalid 5, valid 0. All six zero-count rows were invalid; five were degree-0/component-1 and one degree-1/component-2; no zero-count row was assigned. | Retain all rows; no zero-count filtering sensitivity rerun is justified at this gate. | Do not infer that expression zeros cause invalid neighborhoods, and do not filter only the six rows. | The next criterion is source geometry evidence, not a zero-count rerun. |
| 2026-09 source-geometry gate | The HPG source H5AD and existing sample manifest are available without raw ZIP transfer; source array coordinates, raw pixels, observed in-tissue topology, and manifest diameters can be validated read-only. | Extend the SLURM H5AD audit to emit `source_geometry_summary.csv` and a clearly non-operational `nominal_100um_sensitivity_candidate_scales.csv`. | Defer raw ZIP upload/audit because the local source set is approximately 6 GB and staging would add data-transfer and operational risk; do not run real data locally. | Candidate scales are evidence only and never an input manifest. Pending: review geometry evidence before deciding whether a calibration sensitivity run is warranted. |
| Ongoing operating rule | Full H5AD/real-data reads are scheduled HPG work; local tests use synthetic fixtures. Code changes follow the local edit → test → commit/push → HPG pull workflow, with no real-data processing in the local checkout. | Keep the audit SLURM-only and read-only; preserve transactional publication and unrelated dirty work. | Do not open real H5ADs or process raw ZIPs locally; do not edit code directly on HPG. Only reviewed local commits are pushed then fast-forward pulled. | The next scheduled run must pass launcher rendering, focused tests, and the source/annotated/manifest contracts before execution. |
| Pending decisions | Geometry evidence, calibration, NOVAE domain resolution, and downstream integration have not been independently established. | No correction, domain-resolution change, or downstream Myles/DiSTILL integration is selected yet. | Defer post hoc resolution selection, calibration correction, and downstream feature/model changes. | Decide only after the named evidence gate and a separately pre-specified sensitivity protocol. |
